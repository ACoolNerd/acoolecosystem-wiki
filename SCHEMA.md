# ACoolECOSYSTEM Wiki Schema

## Domain
Global governance, infrastructure, and operational synthesis for the ACoolECOSYSTEM (Holdings, Trust, Nerd, Sing, Finance, Academy, etc.).

## Conventions
- File names: lowercase, hyphens (e.g., `acoolsing-governance.md`)
- YAML frontmatter required on all pages.
- Wikilinks `[[entity-name]]` for hub-and-spoke connectivity.
- Branding: All documentation targets "Timmy Standard" (9.8/10).
- Accent: Orange (#E8520F).

## Tag Taxonomy
- Clusters: infrastructure, media, finance, academy, trust, holdings, nerd
- Operations: manifest, roadmap, governance, meap-phase-2, automation
- Meta: entity, concept, timeline, timmy-score

## Page Thresholds
- **Entity**: Create for any of the 28 planned ecosystem nodes.
- **Concept**: Create for architectural patterns (MEAP, Hub-and-Spoke).
- **Inclusion Policy**: Exclude PII, credential files (e.g., .csv passwords), and non-ecosystem personal media.
